# TradeKit Lite · 外贸工具箱

轻量级外贸单据工作台，支持编辑、预览、保存、打印及 Excel / PDF 导出，无需账号。业务资料保存在当前浏览器，后端提供参考汇率和可选 AI 填写。

公开演示：[tradekit.utilcove.com](https://tradekit.utilcove.com/)。自行部署使用自己的域名与配置。

## 当前功能

- 六类单据：QT 报价单、PI 形式发票、SC 销售合同、CI 商业发票、PL 装箱单、CD 报关信息。共用买卖方、银行、贸易条款和产品表；PI 追加运费，CD 追加报关字段。
- 每类支持多份独立单据、草稿、类型筛选与批量删除，每份保留一份上次保存版本。新建不会覆盖旧单据，编号不是存储主键。
- 十款模板、十种主题、中文/英文/双语；支持产品图片、企业 Logo、产品行复制和资料检索带入。用户内容不自动翻译。
- 卖方、买方和产品目录独立保存。公司按去除首尾空白后的名称匹配；产品须有名称和 SKU，并通过保存或成功输出确认收录。
- Excel 包含字段和图片，金额为静态值；PDF 按内容分页，重复标题/表头并提供页码；打印使用浏览器预览。
- JSON 全量备份、恢复前安全备份、跨标签冲突保护、编辑副本救援和损坏记录隔离。
- 四个城市时钟、四种可选外币对 CNY 参考汇率、本地规则解析和需确认的在线 AI 填写。

## 使用说明

首页选择单据类型，有草稿时可恢复最近修改的草稿。填写内容后约 700ms 自动保存；新建空白不自动入库。“保存”移除草稿标签，“保存草稿”主动设为草稿；继续编辑和输出均不改变状态。保存不校验业务完整性，输出会检查数值。

在“我的单据”打开或删除记录；卖方、买方和产品栏目用于复用独立资料。删除单据不删除目录副本。移动端通过右上角菜单进入导航、备份和项目链接。

定期从“备份 / 恢复”下载 JSON。完整恢复替换全部业务资料，旧单份备份导入为新记录；恢复前会下载安全备份。保存失败时可导出当前编辑副本，完整备份也会保留未保存编辑，恢复时生成新单据。不要清空浏览器存储来排查资料问题。

操作细节、输出限制和故障处理见[使用说明](site/guide.md)。

## 本地开发

需要 Node.js 22+。项目根目录执行，Windows 使用 `npm.cmd`：

```sh
npm ci
npm run server
# 另开终端
npm run dev
```

前端 `http://127.0.0.1:5173`，后端 `http://127.0.0.1:3001`。未配置 AI 不影响制单、导出和本地解析；变量模板见 `.env.example`，保留已有配置。

`localhost`、`127.0.0.1` 及不同端口的资料彼此独立，沿用原地址。前端依赖更新后若出现 Hook 错误，停止旧服务，用 `npm run dev -- --force` 重建缓存；后端修改后重启 `npm run server`。

## 构建与部署

```sh
npm run build
npm start
```

Node 生产服务同时提供 `dist/` 与 `/api/*`。Cloudflare 使用单个 Worker，EdgeOne 必须导入完整源码。正式站点在构建时设置 `SITE_URL`；未配置地址或关闭索引时按预览处理。平台步骤、密钥与 SEO 配置见[部署说明](docs/DEPLOYMENT.md)。

## 当前限制

- 无账号、云同步、多人协作、完整历史或单据类型转换。换地址/浏览器或清除存储后，须从原地址 JSON 备份恢复。
- SC、CI、PL 尚无专属合同签章、运输或装箱编辑模块；CD 整理报关信息，不提交海关申报。编号不保证全局唯一。
- 单张图片最多 2,000,000 字节；完整 JSON 最多 50,000,000 字节，旧单份格式最多 20,000,000 字节。
- PDF 文字为图像，不可搜索；超高单行需缩短或拆分。Excel 不随模板重排。真实打印与交付效果需人工核对。
- 刷新/关闭仅尽力保存，强制终止不保证完成。在线 AI 需同意发送原文、访问口令及候选确认，结果仍须核对。
- 真实供应商、平台发布、手机和完整无障碍验收尚未全部完成；大分包、依赖审查等见[开发指南](docs/DEVELOPMENT.md#7-待办与验收边界)。
