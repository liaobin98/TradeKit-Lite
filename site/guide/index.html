使用说明与常见问题

TradeKit Lite 是开源的浏览器外贸单据工作台：制作六类单据，本地保存资料，导出 Excel、PDF 或通过浏览器打印。

支持的单据制作与保存输出与备份数据与 AI常见问题

支持哪些外贸单据？

QT · 报价单
产品、数量、价格与贸易条款。
PI · 形式发票
付款、交期与银行资料，可填写运费。
SC · 销售合同
买卖方、产品、金额和贸易条款；当前无专属签章模块。
CI · 商业发票
买卖方、产品、金额及贸易条款；当前无专属运输模块。
PL · 装箱单
当前使用含价格的公共产品表；尚无专属装箱字段。
CD · 报关信息
申报要素、运输与海关商品信息；不直接向海关申报。

如何制作、保存和复用资料？

  1. 首页选择单据类型。仅存在同类型草稿时，询问恢复最近草稿或新建。
  2. 填写卖方、买方和产品行；检索目录并明确选择后，才会带入已有内容。
  3. 选择语言、主题和模板，核对字段、图片、合计与预览，再保存或输出。

同类型支持多份独立单据，新建不覆盖旧记录。未填写的新空白单据不自动保存；填写后自动保存为草稿。点击“保存”移除草稿标签，“保存草稿”才主动转回草稿。

已保存单据可以继续编辑。编辑、自动保存、打印与导出不改变其保存状态。卖方、买方与产品目录是独立副本，删除来源单据不会自动删除目录资料。

导出、打印和备份有什么区别？

  • Excel：导出含业务字段、Logo 和产品图片的 XLSX，金额为静态值。
  • PDF：按产品行输出多页 A4 栅格图像，续页重复表头并提供页码，长备注可续页；文字不可搜索。单个超高产品或不可拆分说明需缩短或拆分。
  • 打印：使用浏览器打印预览，只打印单据；长表可分页，请核对边距、分页和底色。
  • JSON 备份：用于恢复编辑资料。恢复完整备份会替换当前资料，并先生成恢复前安全备份。保存失败时，可在备份中保留当前编辑副本，恢复为新单据。

Excel 或 PDF 不能替代 JSON 备份。保存不校验业务内容；导出和打印检查数值，但保存或输出成功不代表交易生效、法律有效或合规认证。

资料是否上传云端？在线 AI 是否联网？

普通填写、预览、保存、导出和打印在浏览器完成。单据、独立资料目录、图片和设置保存在当前浏览器的 IndexedDB，不上传为云端业务档案，不提供跨设备同步。

换浏览器、域名、协议、端口或设备后，无法直接读取原资料。请在原地址下载 JSON 备份，再到新地址恢复；不要通过清空网站数据排查资料丢失。

本地规则解析不联网。在线 AI 是可选功能：用户同意后，所输入文本会发送给配置的模型服务，候选结果需人工核对后采用。访问口令仅保留在当前页面内存，不进入草稿或备份。

参考汇率经后端请求上游，日期是上游数据日期。汇率仅供参考，不构成结算报价、银行承诺或财务建议。

常见问题

必须注册账号吗？

普通制单无需账号。在线 AI 可能需要部署者提供的独立访问口令；这不是用户账号体系。

提供云端保存、多人协作或跨设备同步吗？

不提供。业务资料仅保存在当前浏览器，请定期下载 JSON 备份。

不使用在线 AI，能否制作单据？

可以。普通制单、预览、导出、打印和本地规则解析不依赖在线 AI。页面加载和参考汇率需要网络，没有承诺完整离线运行。

草稿导出后会自动变成已保存吗？

不会。导出和打印不改变状态，需主动点击“保存”移除草稿标签。

保存失败或资料损坏怎么办？

先在“备份 / 恢复”中导出当前编辑副本，或备份全部资料；完整备份会额外保留未保存编辑，恢复时生成新单据。保留副本后可确认重新读取已保存版本。一份单据损坏不影响其他单据，可恢复上一版本；无法进入工作台时，恢复页面也提供备份和恢复入口。不要清空网站数据。

能否直接向海关申报？

不能。CD 是信息整理工具，不是海关申报系统，用户需自行核实适用要求与实际申报流程。

支持手机和主屏幕图标吗？

提供响应式界面、浏览器标签页图标、Apple Touch Icon 与 Android 自适应图标。主屏添加能力取决于浏览器与系统，不代表离线缓存或云端同步。
