## 一句话介绍

TradeKit Lite 是开源的浏览器外贸单据工作台，可在线制作六类单据，将资料保存在当前浏览器，并导出 Excel、PDF 或通过浏览器打印。

## 支持的单据

| 代码 | 名称   | 用途                         |
| -- | ---- | -------------------------- |
| QT | 报价单  | 整理产品、数量、价格及贸易条款            |
| PI | 形式发票 | 整理付款、交期及银行资料，可填写运费         |
| SC | 销售合同 | 整理买卖方、产品、金额和贸易条款；当前无专属签章模块 |
| CI | 商业发票 | 整理买卖方、产品、金额及贸易条款；当前无专属运输模块 |
| PL | 装箱单  | 当前使用含价格的公共产品表；尚无专属装箱字段     |
| CD | 报关信息 | 整理申报要素、运输及海关商品信息；不直接向海关申报  |

## 制单、保存和资料目录

1. 首页选择单据类型；仅存在同类型草稿时询问恢复最近草稿或新建。
2. 填写卖方、买方及产品行，检索已有资料后明确选择，才会带入内容。
3. 选择语言、主题和模板，核对字段、产品图片、金额与实时预览。
4. 同类型支持多份独立单据，新建不覆盖旧记录。
5. 未填写的新空白单据不会自动保存。填写后自动保存为草稿；主动点击“保存”移除草稿标签，“保存草稿”才主动转回草稿。
6. 已保存单据可以继续编辑。编辑、自动保存、打印和导出不会改变其保存状态。

卖方、买方与产品目录是独立资料副本，可检索、查看和删除。公司按名称去重；产品按 SKU 确认收录。删除来源单据不会自动删除独立资料目录。

## 导出、打印和备份

- Excel：导出 XLSX，包含业务字段、Logo 和产品图片；金额是静态值，不能代替可恢复的资料备份。
- PDF：按产品行输出多页 A4 栅格图像，续页重复表头并提供页码，长备注可续页；文字不可搜索。单个产品或不可拆分说明超过一页时会提示缩短或拆分。
- 打印：使用浏览器打印预览，只打印单据；长表可分页，请自行核对分页、边距、底色和交付内容。
- JSON 备份：下载全部业务资料，支持核对后恢复；恢复完整备份会替换当前资料，并先生成恢复前安全备份。
- 保存不校验业务内容；导出和打印会检查数值，但保存或输出成功不代表交易生效、法律有效或已获得合规认证。

## 数据与 AI 的边界

普通填写、预览、保存、导出和打印在浏览器处理。单据、独立资料目录、图片和设置保存在当前浏览器的 IndexedDB，不上传为云端业务档案，不提供跨设备同步。

换浏览器、域名、协议、端口或设备后，不能直接读取原来的本地资料。请先在原地址下载 JSON 备份，再到新地址恢复。清除网站数据可能造成资料丢失。

本地规则解析不联网。在线 AI 是可选功能，部署者需配置供应商密钥及独立访问口令，用户需要同意发送输入文本，并核对候选结果后再采用。模型服务会收到所提交的文本，不能将在线 AI 描述为完全离线。访问口令仅保留在当前页面内存，不进入草稿或备份。

参考汇率由后端向上游获取，日期表示上游数据日期。汇率仅供参考，不构成结算报价、银行承诺或财务建议。

## 常见问题

### 是否必须注册账号？

普通制单无需账号。在线 AI 可能需要部署者提供的独立访问口令；这不是用户账号体系。

### 是否提供云端保存或多人协作？

不提供。资料保存在当前浏览器，不提供账号、云端备份、跨设备同步或多人协作。

### 不使用在线 AI，能否制作单据？

可以。普通制单、预览、导出、打印和本地规则解析不依赖在线 AI。页面加载和参考汇率需要网络；没有承诺完整离线运行。

### 草稿导出后会自动变成已保存吗？

不会。导出和打印不改变状态，需主动点击“保存”移除草稿标签。

### 保存失败或资料损坏怎么办？

先在“备份 / 恢复”中导出当前编辑副本，或备份全部资料；完整备份会额外保留未保存编辑，恢复时生成新单据。保留副本后可确认重新读取已保存版本。一份单据损坏不影响其他单据，可恢复上一版本；无法进入工作台时，恢复页面也提供备份和恢复入口。不要清空网站数据。

### 能否直接向海关申报？

不能。CD 是报关信息整理工具，不是海关申报系统。用户需自行核实适用要求和实际申报流程。

### 浏览器标签页和主屏幕图标是否支持手机？

提供 SVG、ICO、PNG、Apple Touch Icon 和 Android maskable 图标，以及响应式界面。主屏添加能力取决于浏览器与系统；添加图标不代表提供离线缓存或云端同步。
